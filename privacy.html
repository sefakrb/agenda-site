Ajanda – Privacy Policy

Last updated: 13 October 2026

Ajanda ("the app") is a personal Android agenda app developed and used by Sefa Karabaş. This policy explains how the app handles Google user data.

Data the app accesses

  • Google Calendar events (scopes calendar.readonly and calendar.events): titles, times, locations, descriptions and meeting links, to show the agenda, schedule notifications, and create, edit or delete events when the user asks.
  • Google Tasks (scope tasks): task titles, notes and due dates, to show tasks and to add, complete, delete tasks or change due dates when the user asks.
  • Google Drive application data folder (scope drive.appdata): a backup file of the app's own data (saved places, debts, settings). The app has no access to any other Drive file.
  • Email address (scope email): displayed in settings to show which account is connected.

How data is used and stored

Data is fetched directly from Google APIs to the user's device and cached in a local database on that device. It is used only to provide the features described above. Access tokens are not stored; the app requests a fresh authorization from Google before each API call.

Sharing

The app does not send Google user data to any server of mine or to any third party. There is no backend, no analytics, no advertising and no crash reporting. Data is not sold, transferred to others, or used for advertising or to train AI/ML models. No human reads the data.

Limited Use

The app's use and transfer of information received from Google APIs to any other app adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Local data is deleted when the user removes the account in the app or uninstalls it. The optional Drive backup can be deleted from Google Drive's "Manage apps" settings. Access can be revoked at any time at myaccount.google.com/permissions.
